# دنتینو — نرم‌افزار نوبت‌دهی و مدیریت مطب دندانپزشکی

اپ اندروید + نسخه وب، فارسی و تقویم شمسی.

## امکانات
- **تقویم نوبت‌ها**: جدول زمانی روزانه با ستون جدا برای هر پزشک، نوار هفته، تقویم ماهانه شمسی با تعداد نوبت هر روز، ثبت نوبت با یک لمس روی خانه خالی
- **ثبت نوبت هوشمند**: جستجوی بیمار با نام/موبایل/شماره پرونده یا ثبت بیمار جدید در همان فرم، نمایش ساعت‌های پُر، هشدار تداخل نوبت، مدت خودکار بر اساس خدمت
- **وضعیت نوبت**: رزرو ← تأیید ← در مطب (پذیرش) ← انجام شد / لغو / عدم مراجعه
- **پیامک و واتساپ**: پیامک تأیید بعد از ثبت نوبت، لیست یادآوری نوبت‌های فردا، متن قابل تنظیم، تبریک تولد
- **پرونده بیمار**: مشخصات، هشدار پزشکی (حساسیت/بیماری زمینه‌ای) که همه‌جا نمایش داده می‌شود، سابقه نوبت‌ها
- **چارت دندان (FDI)**: ثبت درمان روی هر دندان، طرح درمان و برآورد هزینه باقی‌مانده
- **مالی**: هزینه درمان، پرداخت‌ها (نقدی/کارتخوان/کارت‌به‌کارت/چک/بیمه)، مانده حساب، چاپ صورتحساب، گزارش روزانه/هفتگی/ماهانه/سالانه، لیست بدهکاران
- **لیست انتظار** و تبدیل مستقیم به نوبت
- **چند کاربره و آنلاین** (Supabase): منشی و پزشک روی چند گوشی/کامپیوتر هم‌زمان، تغییرات لحظه‌ای، کار آفلاین و ارسال خودکار بعد از وصل شدن اینترنت
- چاپ برنامه روز، پشتیبان‌گیری/بازیابی JSON، خروجی اکسل (CSV)، پوسته روشن/تیره

## ساختار
```
www/        وب‌اپ (همان چیزی که داخل APK قرار می‌گیرد)
android/    پروژه اندروید (WebView، فایل‌های وب داخل خود APK هستند)
supabase/   schema.sql برای پایگاه داده ابری
.github/    ساخت خودکار APK و انتشار نسخه وب
```

## ساخت APK
با هر push به شاخه main، GitHub Actions فایل APK را می‌سازد و در بخش **Releases** مخزن قرار می‌دهد.
برای امضای ثابت (تا آپدیت‌ها بدون حذف نسخه قبل نصب شوند) دو Secret در مخزن تعریف می‌شود: `KEYSTORE_BASE64` و `KEYSTORE_PASSWORD`.

## راه‌اندازی آنلاین (Supabase) — یک بار
1. در [supabase.com](https://supabase.com) یک پروژه جدید بسازید.
2. **SQL Editor** ← محتوای `supabase/schema.sql` را اجرا کنید.
3. **Authentication → Sign In / Providers → Email**: گزینه **Confirm email** را خاموش کنید.
4. **Authentication → Users → Add user**: کاربر مدیر را بسازید؛ ایمیل به شکل `admin@dentino.app` (در برنامه فقط `admin` وارد می‌شود).
5. **Project Settings → API**: مقدار Project URL و anon public key را در برنامه (تنظیمات ← همگام‌سازی و کاربران) وارد کنید، یا در `www/config.js` بگذارید تا در همه نسخه‌ها از قبل تنظیم باشد.
6. با کاربر مدیر وارد شوید؛ از همان صفحه برای منشی و پزشک کاربر بسازید.

امنیت: فقط کاربرانی که مدیر در برنامه اضافه کرده به داده‌ها دسترسی دارند (RLS). حذف‌ها نرم هستند و قابل بازیابی.

بدون Supabase، برنامه در «حالت محلی» کار می‌کند و داده فقط روی همان دستگاه است (حتماً پشتیبان بگیرید).
